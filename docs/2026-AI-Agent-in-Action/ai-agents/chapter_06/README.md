# Chapter 6: 행동 트리 (Behavior Tree)

## 개요

이 챕터에서는 AI 에이전트의 의사결정 구조 중 하나인 **행동 트리(Behavior Tree)**를 다룬다. `py_trees` 라이브러리를 활용하여 조건 확인과 행동 실행을 트리 구조로 구성하는 방법을 학습한다.

행동 트리는 게임 AI, 로보틱스, 자율 에이전트 등에서 널리 사용되는 의사결정 프레임워크로, 복잡한 행동 로직을 계층적이고 모듈화된 방식으로 표현할 수 있다.

## 파일 설명

| 파일명 | 설명 |
|---|---|
| `first_btree.py` | 행동 트리의 기본 구조를 보여주는 예제 코드. 조건 노드(Condition)와 행동 노드(Action)를 정의하고, Sequence와 Selector 컴포짓 노드를 조합하여 트리를 구성한다. |
| `requirements.txt` | 프로젝트 의존성 패키지 목록. `py_trees` 라이브러리를 사용한다. |

## 핵심 개념

### 노드 유형

- **Behaviour (행동 노드)**: 트리의 기본 단위로, 조건 확인이나 행동 실행을 담당한다. `update()` 메서드에서 `SUCCESS` 또는 `FAILURE` 상태를 반환한다.
- **Sequence (시퀀스)**: 자식 노드를 순서대로 실행하며, 모든 자식이 성공해야 전체가 성공한다. 하나라도 실패하면 즉시 실패를 반환한다.
- **Selector (셀렉터)**: 자식 노드를 순서대로 실행하며, 하나라도 성공하면 전체가 성공한다. 모든 자식이 실패해야 전체가 실패한다.

### 트리 구조 (예제 기준)

```
Selector (루트)
  +-- Sequence 1
  |     +-- Has apple (조건)
  |     +-- Eat apple (행동)
  +-- Sequence 2
        +-- Has pear (조건)
        +-- Eat pear (행동)
```

Selector가 루트 노드로서 두 개의 Sequence를 자식으로 가진다. 먼저 Sequence 1을 시도하고, 실패하면 Sequence 2를 시도하는 **우선순위 기반 의사결정** 구조이다.

### Tick 메커니즘

행동 트리는 매 tick마다 루트 노드부터 순회하며 각 노드의 상태를 평가한다. 예제에서는 3회 tick을 실행하여 트리의 동작을 확인한다.

### Memory 옵션

`memory=True` 설정 시, 이전 tick에서 성공한 자식 노드를 기억하고 다음 tick에서 이어서 실행한다. 이를 통해 상태를 유지하면서 점진적으로 행동을 진행할 수 있다.

## 학습 교훈

1. **행동 트리는 복잡한 의사결정을 단순한 구성 요소로 분해한다.** 조건과 행동을 독립적인 노드로 분리함으로써 각 요소를 개별적으로 테스트하고 재사용할 수 있다.

2. **Sequence와 Selector의 조합이 핵심이다.** 이 두 가지 컴포짓 노드만으로도 AND 논리(Sequence)와 OR 논리(Selector)를 표현할 수 있어, 다양한 의사결정 패턴을 구현할 수 있다.

3. **상태 기반 실행 흐름을 이해해야 한다.** 각 노드가 SUCCESS, FAILURE, RUNNING 중 하나의 상태를 반환하며, 이 상태가 부모 노드의 실행 흐름을 결정한다는 점이 행동 트리의 핵심 메커니즘이다.

4. **모듈화와 확장성이 행동 트리의 장점이다.** 새로운 조건이나 행동을 추가할 때 기존 트리 구조를 크게 변경하지 않고 노드를 추가하거나 교체할 수 있다. 이는 에이전트의 행동을 점진적으로 복잡하게 만들 때 유리하다.

5. **py_trees의 디버깅 기능을 적극 활용한다.** `py_trees.logging.level`을 DEBUG로 설정하면 각 tick에서 노드의 상태 변화를 상세히 추적할 수 있어, 트리 동작을 이해하고 문제를 진단하는 데 도움이 된다.
