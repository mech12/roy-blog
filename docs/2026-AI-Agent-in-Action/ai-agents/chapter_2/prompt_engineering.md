# 프롬프트 엔지니어링 전략 가이드

`prompt_engineering.py`에서 선택하여 실행할 수 있는 6가지 프롬프트 기법입니다.

## 1. `specifying_steps.jsonl` — 단계 지정

LLM에게 **작업 순서를 단계별로 지시**하는 기법. 예: "1단계 - 요약하세요 → 2단계 - 스페인어로 번역하세요" 처럼 복잡한 작업을 순차적으로 분해하여 정확도를 높인다.

## 2. `specify_output_length.jsonl` — 출력 길이 제어

응답의 **분량을 제한**하는 기법. "10단어 이내로", "3개 글머리 기호로" 등 출력 형식과 길이를 명시하여 간결하고 통제된 응답을 얻는다.

## 3. `provide_examples.jsonl` — 예시 제공 (Few-shot)

**입출력 예시를 함께 제공**하여 LLM이 동일한 형식/스타일/길이로 응답하도록 유도하는 기법. 예: Python 설명이 한 문장이었으면, 이후 Java 설명도 한 문장으로 제한.

## 4. `using_delimiters.jsonl` — 구분자 활용

`'''삼중 따옴표'''`나 `<statement>XML 태그</statement>`로 **입력 텍스트의 경계를 명확히 구분**하는 기법. LLM이 지시문과 데이터를 혼동하지 않도록 방지한다.

## 5. `detailed_queries.jsonl` — 상세 질의

같은 주제라도 **질문의 구체성에 따라 답변 품질이 달라짐**을 비교하는 기법. "에이전트란?" (모호함) vs "GPT 에이전트란?" (구체적) 을 비교 실행하여 차이를 확인한다.

## 6. `adopting_personas.jsonl` — 페르소나 부여

LLM에 **특정 역할/정체성을 부여**하여 응답 관점을 바꾸는 기법. 같은 질문("공부하기 좋은 과목?")에 대해 "20세 컴공 학생" vs "38세 간호사"로 완전히 다른 관점의 답변을 생성한다.
