ngrok 설치

1. ngrok 설치 및 계정 설정
Step 1: 회원가입 및 다운로드
ngrok 공식 홈페이지(https://ngrok.com/) 에서 무료 계정을 생성합니다.

각 운영체제(Windows, macOS, Linux)에 맞는 실행 파일을 다운로드합니다.
탭중에 download  선택하기

다운로드한 압축 파일을 적당한 폴더에 풉니다.

ngrok config add-authtoken 356yiHtgnDAmNzaZWEekTBV42rO_772NChe17VbxCiSjSQ8K4


무료버전에서는 도메인 지정 못함
ngrok http --domain=www.example.com  8000
ngrok http 8000


Step 2: 인증 토큰(Auth Token) 등록
터미널(또는 CMD)을 열고, ngrok 홈페이지의 대시보드에 있는 본인의 인증 토큰을 등록합니다.

Bash
ngrok config add-authtoken <본인의_토큰_문자열>
2. ngrok 실행 (서버 외부 노출)
서버가 로컬에서 8000번 포트(FastAPI 기본값)로 실행 중이라고 가정할 때, 다음 명령어를 입력합니다.

Bash
ngrok http 8000
실행하면 터미널창에 Forwarding 주소(예: https://abcd-123-456.ngrok-free.app)가 나타납니다. 이제 전 세계 어디서든 이 주소를 통해 내 컴퓨터의 서버로 접속할 수 있습니다.

3. 주요 명령어 활용
상태 확인: 실행 중인 터미널에서 http://localhost:4040에 접속하면 현재 들어오고 나가는 모든 HTTP 요청을 모니터링할 수 있습니다.

고정 도메인 (무료 버전): 최근 ngrok 무료 버전에서도 1개의 고정 도메인을 제공하므로, 대시보드에서 도메인을 설정한 후 아래와 같이 실행할 수 있습니다.

Bash  고정도메인은 유료일때
ngrok http --url=your-domain.ngrok-free.app 8000

ngrok http 8000 

ngrok http 8000 --host-header="localhost:8000"
