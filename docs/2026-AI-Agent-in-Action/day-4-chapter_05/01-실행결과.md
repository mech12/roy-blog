# Chapter 05 - 실행 결과

- 실행 환경: Qwen3.5-122B-A10B-FP8 (vLLM, `http://10.10.20.20:8000/v1`)
- 실행 일시: 2026-04-04
- Semantic Kernel: v1.36.0 / Python 3.11.5

> Qwen3.5는 thinking 모델이므로 `extra_body={"chat_template_kwargs": {"enable_thinking": False}}`를
> 모든 `OpenAIChatPromptExecutionSettings`에 추가하여 thinking 모드를 비활성화해야 정상 동작합니다.

## 1. OpenAI Function Calling 기초

### first_function.py

```
## 테스트 1: 일반적인 요청
질문: 시간 여행 영화 좀 추천해줄래?
결과: Function(arguments='{"topic": "시간 여행"}', name='recommend_movie')

## 테스트 2: 선호도가 포함된 요청
질문: 정말 재미있는(good) 시간 여행 영화로 추천해줘.
결과: Function(arguments='{"topic": "시간 여행", "rating": "good"}', name='recommend_movie')

## 테스트 3: llm스스로 대답
질문: 심심한데 영화 추천해줄래
결과: 일반 응답: 어떤 주제나 장르의 영화를 선호하시는지 알려주시면 더 좋은 추천을 해드릴 수 있을 것 같아요.
```

- **결과: PASS** - 함수 호출 판단 및 인자 추출 정상 동작

### parallel_functions.py

```
## 테스트 1: 일반적인 요청
사용자 함수 호출

결과: 시간 여행 영화로 **<백 투 더 퓨처 (Back to the Future)>** 를 추천해 드릴게요!

## 테스트 2: 선호도가 포함된 요청
사용자 함수 호출

결과: **추천 영화: 백 투 더 퓨처 (Back to the Future)** - 시간 여행의 고전적인 규칙을 잘 보여줍니다.

## 테스트 3: llm스스로 대답
사용자 함수 호출
질문: 심심한데 영화 추천해줄래
결과: 다양한 장르별 영화 추천 목록 출력 (기생충, 살인의 추억, 극한직업, 인터스텔라 등)
```

- **결과: PASS** - 함수 호출 → 로컬 실행 → 결과 재전달 → 최종 답변 생성 정상
