## 호환성 수정 사항 (py-trees 2.4.0)

| 파일 | 수정 내용 |
|------|-----------|
| `가드.py` | `hasattr()` → `try/except KeyError` (블랙보드 미존재 키 접근 시 KeyError 발생) |
| `데코레이터.py` | `num_attempts` → `num_failures` (API 변경) |
| `리액티브.py` | `getattr()` → `try/except KeyError` (블랙보드 미존재 키 접근 시 KeyError 발생) |
