# Semantic Kernel 커뮤니티에 오신 것을 환영합니다!

아래는 SK 커뮤니티에 참여할 수 있는 방법들입니다.

## GitHub에서 참여하기

- [토론(Discussions)](https://github.com/microsoft/semantic-kernel/discussions): 질문하고, 피드백을 제공하며, Semantic Kernel에서 보고 싶은 기능에 대한 아이디어를 공유하세요.
- [이슈(Issues)](https://github.com/microsoft/semantic-kernel/issues) - 버그, 예상치 못한 동작을 발견하거나 기능 요청이 있으면 이슈를 등록해 주세요.
- [풀 리퀘스트(Pull Requests)](https://github.com/microsoft/semantic-kernel/pulls) - 기여를 환영합니다! [기여 가이드](https://github.com/microsoft/semantic-kernel/blob/main/CONTRIBUTING.md)를 참조해 주세요.

모든 제출 사항에 가능한 한 빠르게 응답하도록 노력하고 있습니다.

## 공개 커뮤니티 오피스 아워

**누구나 참여 가능한** 정기 커뮤니티 오피스 아워를 운영하고 있습니다.

Semantic Kernel 이벤트를 캘린더에 추가하세요. 서로 다른 시간대를 고려하여 두 가지 Q&A 오피스 아워를 운영하고 있습니다:

- **아메리카 & EMEA 시간대:** 매주 수요일 태평양 시간 오전 8:00 / 중부유럽 시간 17:00. 서머타임에 맞게 조정됩니다. 참여 링크: [SK-Americas-Europe-OfficeHours](https://aka.ms/sk-officehours).
- **아시아 태평양 시간대:** 매월 두 번째 수요일 태평양 시간 오후 4:00. 아시아 대부분 지역에서는 목요일 현지 시간에 해당합니다. 서머타임에 맞게 조정됩니다. 참여 링크: [SK-APAC-OfficeHours](https://aka.ms/sk-apac-officehours).

질문이 있거나 프로젝트를 소개하고 싶으시면 다룰 주제를 skofficehours[at]microsoft.com으로 이메일해 주세요.

실시간으로 참석하지 못하시더라도 모든 회의는 녹화되어 온라인에 게시됩니다.

## Discord 커뮤니티에서 참여하기

질문하고, 프로젝트를 공유하며, 커뮤니티로부터 도움을 받기에 좋은 공간입니다.

Discord 링크로 참여하세요: [aka.ms/SKDiscord](https://aka.ms/SKDiscord)
