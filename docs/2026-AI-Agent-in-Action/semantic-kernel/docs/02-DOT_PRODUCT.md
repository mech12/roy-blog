# 내적 (Dot Product)

내적은 같은 길이의 두 벡터를 받아 하나의 스칼라 값을 반환하는 수학 연산입니다.
스칼라 곱(scalar product) 또는 내적(inner product)이라고도 합니다.
두 벡터의 내적은 각 벡터의 대응하는 요소를 곱한 뒤 그 결과를 합산하여 계산합니다.

내적은 컴퓨터 과학, 특히 인공지능과 머신러닝에서 다양하게 활용됩니다.
내적의 대표적인 활용 사례 중 하나는 단어 [임베딩](EMBEDDINGS.md)이나 이미지
임베딩과 같은 두 벡터 간의 유사도를 측정하는 것입니다. 이는 데이터셋에서
유사한 단어나 이미지를 찾고자 할 때 유용합니다.

AI에서 내적은 두 벡터 간의 [코사인 유사도](COSINE_SIMILARITY.md)를 계산하는 데
사용할 수 있습니다. 코사인 유사도는 두 벡터 사이의 각도를 측정하며, 각도가
작을수록 유사도가 높음을 나타냅니다. 이는 [유클리드 거리](EUCLIDEAN_DISTANCE.md)가
정확한 유사도 측정이 어려울 수 있는 고차원 데이터를 다룰 때 유용합니다.

AI에서 내적의 또 다른 응용은 신경망에서 뉴런 입력의 가중합을 계산하는 것입니다.
이 계산은 신경망의 순전파(forward propagation)에 필수적입니다.

전반적으로 내적은 AI와 임베딩을 다루는 소프트웨어 개발자에게 중요한 연산입니다.
벡터 간 유사도를 측정하고 신경망에 필요한 계산을 수행하는 간단하면서도
강력한 방법을 제공합니다.

# 응용 분야

내적 응용 분야의 몇 가지 예시입니다.

1. 추천 시스템: 내적은 추천 시스템에서 사용자나 항목을 나타내는 두 벡터 간의
   유사도를 측정하여 특정 사용자에게 가장 관심 있을 만한 항목을 식별하는 데
   사용할 수 있습니다.

2. 자연어 처리(NLP): NLP에서 내적은 단어 임베딩 간의 코사인 유사도를 구하는 데
   사용할 수 있으며, 이는 동의어 찾기나 관련 단어 식별과 같은 작업에 유용합니다.

3. 이미지 인식: 내적은 이미지 임베딩을 비교하는 데 사용할 수 있어,
   보다 정확한 이미지 분류와 객체 탐지가 가능합니다.

4. 협업 필터링: 사용자와 항목 임베딩의 내적을 구함으로써, 협업 필터링 알고리즘은
   특정 사용자가 특정 항목을 얼마나 좋아할지 예측할 수 있습니다.

5. 클러스터링: 내적은 텍스트나 이미지 임베딩을 다룰 때와 같이 고차원 공간에서
   데이터 포인트를 클러스터링할 때 거리 메트릭으로 사용할 수 있습니다.

6. 이상 탐지: 임베딩의 내적을 가장 가까운 이웃들의 내적과 비교함으로써,
   지역 이웃 내 다른 데이터 포인트와 크게 다른 데이터 포인트를 식별하여
   잠재적 이상치를 발견할 수 있습니다.
