# 유클리드 거리 (Euclidean Distance)

유클리드 거리는 유클리드 공간에서 두 점 사이의 직선 거리를 측정하는 수학적
개념입니다. "기하학의 아버지"라고 불리는 고대 그리스 수학자 유클리드의 이름을
따서 명명되었습니다. 유클리드 거리를 계산하는 공식은 피타고라스 정리에 기반하며
다음과 같이 표현됩니다:

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

고차원의 경우 이 공식은 다음과 같이 일반화할 수 있습니다:

$$d(p, q) = \sqrt{\sum\limits_{i\=1}^{n} (q_i - p_i)^2}$$

유클리드 거리는 컴퓨터 과학과 인공지능에서 다양하게 활용되며, 특히
[임베딩](EMBEDDINGS.md)을 다룰 때 중요합니다. 임베딩은 데이터의 기본 구조와
서로 다른 데이터 포인트 간의 관계를 포착하는 수치 표현입니다.
자연어 처리, 컴퓨터 비전, 추천 시스템에서 흔히 사용됩니다.

임베딩을 다룰 때 서로 다른 데이터 포인트 간의 유사도 또는 비유사도를 측정해야
하는 경우가 많습니다. 이때 유클리드 거리가 활용됩니다. 두 임베딩 간의 유클리드
거리를 계산하면 얼마나 유사한지 또는 다른지를 판단할 수 있습니다.

AI에서 유클리드 거리의 대표적인 활용 사례 중 하나는 K-means와 같은 클러스터링
알고리즘입니다. 이 알고리즘에서 데이터 포인트는 다차원 공간에서의 근접성을
기준으로 그룹화됩니다. 각 포인트와 해당 클러스터 중심점(centroid) 간의
유클리드 거리를 사용하여 어떤 포인트가 어떤 클러스터에 속하는지 결정합니다.

유클리드 거리의 또 다른 활용 사례는 추천 시스템입니다. 서로 다른 항목의
임베딩 간 유클리드 거리를 계산하여 항목 간의 유사도를 판단하고,
그 정보를 기반으로 추천을 제공할 수 있습니다.

전반적으로 유클리드 거리는 AI와 임베딩을 다루는 소프트웨어 개발자에게 필수적인
도구입니다. 다차원 공간에서 서로 다른 데이터 포인트 간의 유사도 또는 비유사도를
측정하는 간단하면서도 강력한 방법을 제공합니다.

# 응용 분야

유클리드 거리 응용 분야의 몇 가지 예시입니다.

1. 추천 시스템: 유클리드 거리는 추천 시스템에서 항목 간의 유사도를 측정하여
   보다 정확한 추천을 제공하는 데 사용할 수 있습니다.

2. 이미지 인식: 이미지 임베딩 간의 유클리드 거리를 계산하면 유사한 이미지를
   식별하거나 중복을 탐지할 수 있습니다.

3. 자연어 처리: 단어 임베딩 간의 거리를 측정하면 의미적 유사도 및
   단어 의미 중의성 해소(word sense disambiguation)와 같은 작업에 도움이 됩니다.

4. 클러스터링: 유클리드 거리는 클러스터링 알고리즘의 메트릭으로 흔히 사용되어
   유사한 데이터 포인트를 함께 그룹화할 수 있게 합니다.

5. 이상 탐지: 데이터 포인트 간의 거리를 계산하면 데이터셋에서
   이상치나 비정상 데이터를 식별할 수 있습니다.
