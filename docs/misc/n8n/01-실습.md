# 01. n8n 첫 실습 — 수동 트리거 + HTTP Request

> n8n을 처음 접한 사용자를 위한 가장 기본적인 워크플로우 구성 실습 기록입니다.
> **수동 버튼 → 공개 REST API 호출 → 결과 확인** 흐름을 직접 만들어 보면서 n8n의 핵심 개념(노드/아이템/트리거)을 체험합니다.
>
> 사전 준비 문서: [n8n소개.md](./n8n소개.md)

---

## 0. 실습 환경

| 항목 | 값 |
|------|-----|
| 플랫폼 | macOS (Darwin) |
| 컨테이너 런타임 | Docker Desktop |
| n8n 이미지 | `docker.n8n.io/n8nio/n8n` (latest) |

n8n 컨테이너가 이미 실행 중인 상태에서 시작합니다. 설치 방법은 [n8n소개.md — 6. macOS에서 Docker로 로컬 설치하기](./n8n소개.md#6-macos에서-docker로-로컬-설치하기) 참고.

## 1. 초기 세팅 — Owner 계정 생성

처음 <http://localhost:5678> 에 접속하면 `/setup` 으로 리다이렉트되며 **Set up owner account** 폼이 나타납니다.

| 필드 | 입력값 |
|------|--------|
| Email | `user@example.com` |
| First Name | `Hong` |
| Last Name | `Gildong` |
| Password | `********` (대문자·숫자 포함 8자 이상) |

### 비밀번호 규칙 주의
- 최소 8자
- 숫자 1개 이상
- **대문자 1개 이상** (소문자만 있으면 검증 실패)

`Next` 클릭 → `/home/workflows` 로 리다이렉트.

### 온보딩 화면 세 가지
계정 생성 직후 다음 세 화면이 순차적으로 나타납니다.

1. **Customize n8n to you** (설문) — 회사/역할/규모 등 5개 드롭다운. 선택 후 `Get started`.
2. **Get paid features for free (forever)** (프로모션 모달) — 무료 라이선스 키 유도. `Skip` 가능.
3. **👋 Welcome, <First Name>!** (홈 대시보드) — `Create your first workflow` 카드와 `Start from scratch` 버튼 노출.

---

## 2. 새 워크플로우 만들기

홈 화면의 **Start from scratch** 카드 클릭 → 빈 에디터로 진입.

- URL이 `/workflow/<random-id>?new=true` 로 이동
- 캔버스 중앙에 `+ Add first step…` 점선 박스 1개
- 기본 워크플로우명은 `My workflow`

---

## 3. 1단계 — 트리거 노드 추가 (Manual Trigger)

`+ Add first step…` 클릭 → 우측에 **"What triggers this workflow?"** 패널이 열립니다.

### 트리거 선택지 (상단부터)
| 트리거 | 설명 |
|--------|------|
| **Trigger manually** ✅ 이번 실습 | n8n UI 버튼 클릭으로 실행. 학습용 최적 |
| On app event | Telegram/Notion/Airtable 등 외부 앱 이벤트 |
| On a schedule | Cron 스케줄 |
| On webhook call | HTTP 요청 수신 시 |
| On form submission | n8n 내장 웹폼 제출 시 |
| When executed by another workflow | 다른 워크플로우에서 호출 |
| On chat message | AI 노드와 연계되는 챗 메시지 |

**Trigger manually** 선택 → 캔버스에 **"When clicking 'Execute workflow'"** 노드가 추가됩니다.

---

## 4. 2단계 — HTTP Request 노드 연결

### 노드 패널 열기
우측 상단의 **"Open nodes panel"** (`+` 아이콘) 버튼 클릭 → **"What happens next?"** 패널 노출.

카테고리:
- **AI** — 에이전트, 문서 요약/검색
- **Action in an app** — 외부 앱 액션
- **Data transformation** — 변환/필터
- **Flow** — 분기/머지/반복
- **Core** — 코드 실행, **HTTP Request**, 웹훅 등
- **Human review** — 수동 승인
- **Add another trigger**

### 검색으로 빠르게 찾기
검색창에 `http request` 입력 → **HTTP Request** 노드 1개 필터링 → 클릭.

HTTP Request 노드가 트리거 노드와 자동 연결되고, 오른쪽에서 노드 설정 모달이 열립니다. URL 이 `/workflow/<id>/<nodeId>` 형태로 바뀝니다.

---

## 5. 3단계 — HTTP Request 설정

### 입력값

| 파라미터 | 값 | 비고 |
|----------|-----|------|
| **Method** | `GET` | 기본값, 변경 없음 |
| **URL** | `https://catfact.ninja/fact` | 랜덤 고양이 지식 반환 공개 API |
| **Authentication** | `None` | 인증 불필요 |
| Send Query Parameters | OFF | |
| Send Headers | OFF | |
| Send Body | OFF | |

### 왜 `catfact.ninja`?
- 무료, 인증 불필요, HTTPS 지원
- 즉시 응답
- 응답 스키마가 간단 (`fact`, `length` 두 필드)
- 데모/학습용으로 이상적

> 실무에서는 여기에 GitHub API, OpenAI API, 사내 REST API 등을 꽂으면 됩니다.

---

## 6. 4단계 — 노드 단독 실행 (Execute step)

노드 설정 모달 우측 상단의 주황색 **Execute step** 버튼 클릭.

### 결과 — Output 패널 (Table 뷰)

| fact | length |
|------|--------|
| `Like humans, cats tend to favor one paw over another` | `52` |

### Output 뷰 전환
오른쪽 상단 라디오: `Schema` / `Table` / `JSON` 세 가지 뷰 제공.

**JSON** 탭으로 바꾸면 원본 응답이 그대로 보입니다.

```json
{
  "fact": "Like humans, cats tend to favor one paw over another",
  "length": 52
}
```

### 핵심 이해
- `Execute step`은 **이 노드 한 개만** 즉시 실행해서 결과를 확인하는 기능입니다.
- 입력 데이터가 필요한 경우 n8n이 이전 노드를 함께 실행해 줍니다.
- 실무에서 노드 설정을 디버깅할 때 가장 많이 쓰는 버튼.

---

## 7. 5단계 — 전체 워크플로우 실행 (Execute workflow)

노드 설정 모달을 `X` 로 닫아 캔버스 전체 뷰로 돌아온 뒤, 하단 중앙의 주황색 **Execute workflow** 버튼 클릭.

### 실행 결과
```
┌──────────────────────────────┐      ┌──────────────────────────────┐
│  ▶ When clicking              │─────▶│  🌐 HTTP Request              │
│    'Execute workflow'         │ 1 item│  GET catfact.ninja/fact       │
│                    1 item     │      │                     1 item    │
└──────────────────────────────┘      └──────────────────────────────┘
```

- 두 노드 모두 상단에 **"1 item"** 라벨 표시
- 연결선이 녹색 계열로 활성화 → 데이터가 정상적으로 흘렀다는 의미
- 상단 페이지 타이틀이 `▶️ My workflow - n8n` 으로 잠시 바뀜(실행 중 표시)

---

## 8. 전체 단계 요약

| # | 액션 | 결과 |
|---|------|------|
| 1 | 홈에서 `Start from scratch` 클릭 | 빈 워크플로우 에디터 진입 |
| 2 | `Add first step…` → `Trigger manually` 선택 | Manual Trigger 노드 생성 |
| 3 | `Open nodes panel` → `http request` 검색 → 선택 | HTTP Request 노드 자동 연결 |
| 4 | URL 필드에 `https://catfact.ninja/fact` 입력 | GET 요청 준비 완료 |
| 5 | `Execute step` 클릭 | Output 패널에 JSON 응답 표시 |
| 6 | Output 탭을 `Table → JSON` 전환 | 원본 응답 구조 확인 |
| 7 | 설정 패널 닫고 `Execute workflow` 클릭 | 트리거 → HTTP Request 체인 전체 실행 |

## 9. 이 실습으로 익힌 n8n 핵심 개념 3가지

### 9.1 노드(Node)
- 워크플로우의 한 단계
- 이전 노드의 **출력(Output)** 이 다음 노드의 **입력(Input)** 이 됨
- 400개 이상의 내장 노드 제공 (HTTP Request, Slack, Postgres, OpenAI 등)

### 9.2 아이템(Item)
- 노드 간에 흐르는 **데이터 단위**
- 이번 실습에서는 `{fact, length}` 객체 **1개**가 흘렀음
- 아이템이 여러 개면 n8n이 **자동으로 반복 실행** (for 루프 불필요)

### 9.3 트리거(Trigger)
- 워크플로우의 **시작점** 역할을 하는 특수 노드
- 종류: Manual / Schedule(Cron) / Webhook / App Event / Form / Chat 등
- 이번 실습은 가장 단순한 **Manual Trigger** 사용

## 10. 확장 아이디어

이 실습 워크플로우를 기반으로 다음 단계로 확장할 수 있습니다.

| 다음 단계 | 추가할 노드 | 배우는 것 |
|----------|------------|-----------|
| ① `fact` 값만 뽑아 새 필드로 정리 | **Set / Edit Fields** | 데이터 필드 선택·변환 |
| ② `length > 100` 인 경우만 처리 | **IF** | 조건 분기 |
| ③ 결과를 Slack / Gmail / Discord 로 전송 | **Slack / Gmail** | 외부 서비스 연동 + 자격 증명 관리 |
| ④ 매일 아침 9시 자동 실행 | **Schedule Trigger** | Cron 기반 자동화 |
| ⑤ LLM으로 한국어 번역·요약 | **OpenAI / Anthropic** | AI 에이전트 기초 |
| ⑥ `https://catfact.ninja/facts` (복수형) 호출 | 기존 HTTP Request 수정 | 다중 아이템 자동 반복 처리 |

## 11. 트러블슈팅 팁 (이번 실습에서 경험한 것)

### 비밀번호 검증 실패
- 증상: Owner 계정 생성 시 Next 버튼이 눌리지 않거나 오류 표시
- 원인: 비밀번호에 **대문자 없음**
- 해결: `Example1` 처럼 대문자 1개 이상 포함

### "Learn JSON basics" 탭이 새로 열림
- 증상: `Start from scratch` 클릭 시 튜토리얼 페이지가 새 탭으로 열림
- 원인: n8n 내장 안내
- 해결: 무시하고 원래 탭에서 작업 진행
